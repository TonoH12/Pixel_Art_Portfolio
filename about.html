ABOUT ME

Hi, I'm Shriya, an aspiring coder! I started (dabbled) coding during elementary school, but I only got invested during the pandemic. Since then, I've learned several new skills and created a few projects - with many more to come!

I started drawing pixel art only a few months ago, since I wanted to create my own game assets for a video game. After some time, I realized I had a bunch of art lying around, so I thought - why not display it in a website? And as a result... this website was born!

All art displayed on this website is hand-drawn, and are completely human-made(aka me!). It was made using Piskel, a free website for pixel art, and the palletes used here either from Lospec or made by me.
